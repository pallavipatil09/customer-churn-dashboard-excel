# Excel Churn Analysis Dashboard

This project is an interactive Excel Churn Analysis Dashboard created to analyze customer churn behavior and generate retention insights.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Formulas (COUNTIFS, SUMIFS, IF, XLOOKUP)

## Key KPIs
- Total Customers
- Churned Customers
- Churn Rate %
- Active Customers
- Average Monthly Charges
- Average Tenure

## Dashboard Features
- Interactive slicers for filtering
- Churn by contract type
- Churn by payment method
- Churn by internet service
- Tenure group analysis
- Monthly charges vs churn
- KPI cards for quick insights

## Files Included
- Churn_Dashboard.xlsx
- Dataset.csv
- Dashboard Screenshot.png

## Business Insights
- High churn customer segments identified
- Contract type impact analyzed
- Payment behavior patterns found
- Retention opportunities highlighted

## Purpose
This project demonstrates Excel dashboarding, customer analytics, data visualization, and business problem-solving skills for Data Analyst roles.
